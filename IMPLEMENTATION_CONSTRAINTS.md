# Implementation Constraints

These constraints are intentional and should be treated as priorities.

- React + TypeScript frontend
- Node.js + TypeScript backend
- SQLite database
- Prisma ORM
- Tiptap editor
- Seeded users instead of real authentication
- No OAuth
- No JWT
- No RBAC
- No real-time collaboration
- No WebSockets
- No Yjs
- No CRDT
- No comments
- No version history
- Support only .txt and .md uploads
- Minimal UI
- Focus on satisfying requirements with the smallest reasonable implementation
